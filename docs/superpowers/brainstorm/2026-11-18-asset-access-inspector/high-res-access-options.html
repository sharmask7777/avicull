How the 3 Storage Scenarios Are Handled Across All Options

🟢 1. Local Disk (APFS)

File is present on disk. Instant copy path, open in default app, or reveal in Finder. Zero latency, 100% offline.

☁️ 2. Cloud Evicted (Darwin SF_DATALESS)

File is a dataless cloud pointer (iCloud/Dropbox/OneDrive). Provides a 1-click shell command (e.g. open -R or on-demand stream) to safely hydrate only that specific RAW without downloading gigabytes of adjacent archive.

🌐 3. NAS Directory Mount

File lives on SMB/NFS share (e.g. /Volumes/PhotoNAS/...). Shows mount status (Mounted vs Unmounted), NAS share URI (smb://nas.local/...), and 1-click terminal mount / open command.
