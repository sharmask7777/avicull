Asset Access Inspector: Final Agreed Design

Complete specification for the Right-Side Inspector Drawer in catalog.html.

🎯 Triggers & Interaction Model

  • Open Drawer: Click the black path pill on any photo card.
  • Live Switching: While drawer is open, clicking anywhere on any photo card immediately switches the inspector to that photo.
  • Dismiss: Click ✕ button, press Esc, or click the active card's path again.
  • Card Affordance: The path pill has a pointer cursor, subtle blue hover border, and 🔍 icon with tooltip.

📋 Inspector Drawer Content

  • Header: Photo thumbnail + species name + original stem + close button.
  • Storage Status: Auto-detects 🟢 Local APFS, ☁️ Cloud Evicted (Darwin SF_DATALESS), or 🌐 NAS Directory Mount.
  • Primary RAW Path: Full absolute path with 1-click clipboard copy.
  • Companion Bundle: Lists paired JPEGs, RAWs, and .xmp sidecars with copy buttons.
  • One-Click Commands: open -R (Finder reveal), on-demand cloud hydration (cat > /dev/null), and NAS mount commands.
